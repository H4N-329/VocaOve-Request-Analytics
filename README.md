# ボカオバリクエスト分析 v3.5 — 楽曲動画リンク対応

## 今回の変更

- **投稿データ一覧の曲名がクリック可能になりました。**
- 元のGoogleスプレッドシートに `動画URL`（任意）の列を増やし、**実際のYouTube動画かニコニコ動画の視聴ページURL**を記入すると、曲名クリックでその動画を直接開きます。
- **同じ曲名＋アーティスト**のほかの投稿にも、確認済み動画URLを自動的に共有します。原則として同一曲ごとに1件記載すればOKです（別アーティストの同名曲は共有しません）。
- さらに `YouTube URL` / `ニコニコ動画URL` を別々に持つ場合も列名の自動判定に対応します。動画の優先順位は YouTube列 → ニコニコ列 → 共通動画URL列 です。
- **動画URLのない曲は、曲名＋アーティスト名でYouTube検索結果を開きます。** このとき画面に `YouTube検索結果` と明記し、元動画への直接リンクであると誤認させないようにしています。ニコニコ動画検索の補助リンクも表示します。
- 確定した動画URLがあれば `YouTube 動画` / `ニコニコ動画 動画` と表示します。
- URLの検証でYouTubeまたはニコニコの一般的な視聴ページ以外のリンクは開きません。HTTPSのみを許可します。
- 列設定（ページ下部）に `動画URL`・`YouTube URL`・`ニコニコURL` の任意選択欄を追加しました。
- 投稿データCSVに動画URL列を追加しました。
- 他のランキング、レギュラーDJ4名の表示切替、シートの5分更新、UI配色・レイアウトは維持しています。

## 実際に動画を直接開く方法

現在のシート（曲名、アーティスト、投稿日、ユーザー、X投稿URL）に、次の1列を追加してください。

| 曲名 | アーティスト | 動画URL |
| --- | --- | --- |
| （曲名） | （制作者名） | `https://www.youtube.com/watch?v=…` または `https://www.nicovideo.jp/watch/sm…` |

1. Googleスプレッドシートの見出し行に **`動画URL`** を追加。各行へ実際の曲の動画リンクを入力。
2. Webアプリの「データ管理・更新 → データを更新」をクリック（5分ごとの自動反映も可）。
3. 「列の設定」で `動画URL` が認識されているか確認し、必要なら手動で選択して「この列設定で集計」。
4. 「投稿データ一覧」の曲名をクリックすると、登録された動画が別タブで開きます。

動画URLの登録は任意です。登録前からすべての曲名をクリックできますが、その場合は**YouTube検索結果であり、個別の確定動画ではありません**。同名曲、カバーやRemixを取り違えないための仕様です。

## 更新方法

現行のGitHubリポジトリの `main` ブランチのリポジトリ**直下**へ、ZIP内の各ファイル・フォルダを上書きアップロードしてコミット。Vercelが自動再デプロイします。新しいVercelプロジェクトは必要ありません。

## その他

Google Sheets取得API（`api/sheet.js`）は既存のまま。投稿ランキングその他の集計ルールはv3.4を引き継いでいます。Vercelの追加のAPIキー・新規サービス契約は必要ありません。動画URLを確定せず自動的に公式動画を推定する仕組みは今回実装していません。検索先はYouTube・ニコニコ動画です。
