# #ボカオバリクエスト分析 v3.6 — VocaDB 動画候補検索

## 追加内容

- **投稿データ一覧**で動画未登録の楽曲名をクリックすると、曲名・アーティスト名を使用して **VocaDB公開API** を自動検索します。
- 登録候補を曲名＋アーティスト名の一致度で並べ替え、VocaDB楽曲ページ・YouTube／ニコニコ動画URL・動画投稿者・動画種別（VocaDBに登録されている範囲）を表示します。
- 「**動画確認**」で実際のページを開き、正しい動画なら「**この動画を採用**」。この操作なしに自動採用しません。
- 採用リンクはブラウザのlocalStorageに保存され、**同じ曲名＋アーティスト名**のほかの投稿にも反映されます。ページの更新後も保持されます。
- ページ下部の「確定した動画リンク」から `video-links.json` をダウンロードし、GitHubのリポジトリ直下に配置すると**全閲覧者に共有**できます。
- URLがスプレッドシートに登録されている場合は、**シート側のURLが最優先**。ブラウザ採用が共通JSONより優先です。
- VocaDBに登録がない場合、またはAPIが利用できない場合は **YouTube／ニコニコ検索へのリンク**を表示します。
- APIキーなしで利用できるVocaDBの公開REST APIを、Vercel Functions `/api/vocadb` から呼び出します。検索対象は固定のVocaDBドメインのみ、キャッシュはサーバー約1時間、画面を開いている間は同曲の検索結果を再利用します。
- 大量APIアクセスを避けるため、**開いた楽曲だけを自動検索**します。約700件を一括照会する仕組みではありません。

### 注意 — 公式動画であることは保証できません

VocaDBはコミュニティ登録データです。曲名・制作者が一致する動画でも、カバー／Remix／転載の場合があります。**採用前に必ず動画の投稿者・タイトル・内容を確認**してください。VocaDBの登録された動画のうち、YouTube／ニコニコのHTTPS視聴URLだけを表示します。

## 公開手順（既存のGitHub・Vercelを維持）

1. このZIPを解凍します。
2. 各ファイルを**今のGitHubリポジトリのルート（`index.html` がある場所）**へ追加・上書きします。フォルダごと余計な階層に入れないでください。
3. `api/vocadb.js`、`lib/vocadb.mjs`、`video-links.json` が新たに増えます。既存の `api/sheet.js` は変更していません。
4. `Commit changes`。Vercelの `Deployments` が `Ready / Production` になったらサイトにアクセスします。
5. 投稿一覧で動画未登録の曲名をクリックするとVocaDBの候補が表示されます。
6. 採用したものを全員に反映する場合は、ページ下部で出力した `video-links.json` をGitHubに上書きアップロードしてください（**ブラウザ上で確定するだけでは他の利用者には共有されません**）。

### 上書き時の注意

- GitHubに**すでに `video-links.json` が存在する場合は、その中の確定済みリンクを消さないように注意**してください。今回のZIP同梱ファイルは初期状態 `{}` です。
- 確定済みリンクを維持するには、前述の「確定リンクをJSON保存」で取得したものを使用します。
- Google Sheetsのデータ・gid・列の設定・既存ランキングはそのまま。5分間隔のデータ自動更新も維持します。
- スプレッドシートの動画URL列が存在しなくても機能します。
- テストはスタブしたVocaDB APIを使った自動／ブラウザ確認です。**VocaDBの本番APIへの実接続は、この作業環境ではネットワーク制限で未検証です**。Vercel公開後に実際の曲で確認してください。

## 技術構成

静的HTML/JS/CSS + Node.js Vercel Functions（外部APIプロキシ）。外部パッケージ不要、Node.js 18+。ローカル単体テスト `npm test`。

VocaDB公式APIの説明： https://wiki.vocadb.net/docs/public-api
